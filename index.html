Metodología de Excelencia Docente

Cómo Dominar las Transiciones Fluidas

Guía práctica para conectar objetivos comunicativos sin romper el hilo conductor y potenciar tu evaluación institucional.

🛑 El Diagnóstico: ¿Qué debemos evitar?

Para lograr una conexión sutil, primero debemos eliminar las rupturas drásticas en el aula:

  • “Well, we have finished this class. now let's move to the class X”.
  • “Ready, next topic. Let's check grammar”.
  • “Time is done for this activity, let's pass to the other”.

🛠️ Las 4 Estrategias de Conexión

1. El Puente de Causa y Efecto

Principio: El cierre de la Clase A siembra de forma obligatoria la necesidad de abrir la Clase B.

Cómo hacerlo: Usa los últimos minutos para lanzar una pregunta o un reto que solo se resuelva con la nueva estructura.

“¡Excellent! We accomplished to [Logro A]. But now we have the real deal: ¿how do we do to [Objetivo B]? Let's discover it on the page...”

2. Enfoque de "Macro-Misión"

Principio: Todo el bloque de 6 clases se desarrolla dentro de un gran caso real o proyecto del día.

Cómo hacerlo: Presenta la meta global al inicio. Introduce cada nuevo tema como el siguiente paso indispensable para completar el reto.

“We have finished the first step that was [Tema 1], to continue the journey we need the tools that we have on the page x...”

3. Reciclaje por el Estudiante

Principio: La última participación de tus estudiantes se convierte de inmediato en la introducción de la nueva clase.

Cómo hacerlo: Escucha los closures, extrae una idea clave que haya dicho un estudiante y úsala de puente hacia el siguiente tema.

“[Nombre] talked about a crucial point: [Opinión]. For everyone of us to learn how to formulate the same idea in a correct way, we are going to check the examples on ...”

4. Anclaje Visual y de Material

Principio: Ubicar al estudiante en el libro de forma narrativa e integrada, sin dar órdenes mecánicas.

Cómo hacerlo: Conecta lo que ven proyectado o en el tablero con los elementos gráficos de la página de destino.

“Look at this situation on the screen... that is the same dilemma that the characters on the page 34 have, so let's check that...”

🗣️ Banco de "Frases Pegamento"

Úsalas en tu planeación diaria para que tu discurso fluya de forma natural:

"This makes the link to our next challenge..."
"Now that we know the vocabulary, let's use it for real with the next examples..."
"To level up this that we have learned let's use it with the next examples..."
"Take a look on the page x, that is where we are going to use this..."

🤖 Automatiza tu Planeación: Configura tu Asistente de IA

Copia los siguientes parámetros de personalización para crear tu propio **GEM** personalizado y automatizar el diseño de tus celdas de transiciones en segundos:

Nombre del GEM: LINKIN' PLAN (I DON'T KNOW WHY)

Descripción: Eres un Asistente de Planeación Académica y Mentor de Docentes experto en la metodología Smart. Tu único objetivo es ayudar al usuario a diseñar transiciones fluidas y naturales entre clases consecutivas (bloques de hasta 6 clases), asegurando que se perciban como un único hilo conductor y eliminando cambios bruscos de tema.

Instrucciones (System Prompt) para pegar en tu IA:

You are an expert Academic Planning Assistant and Teacher Mentor for Smart methodology. Your sole purpose is to help the user design seamless, fluid transitions between consecutive classes (blocks of up to 6 classes), ensuring they feel like a single, cohesive learning journey and eliminating abrupt topic changes. CRITICAL RULE: You must output your response ONLY in English. Your decisions and suggestions must be STRICTLY based on the communicative objectives PDF files uploaded to your Knowledge. When the user provides the classes for their block, you must generate a structured planning proposal formatted as a markdown table (grid) so the user can easily copy and paste it into Google Sheets. The table must include the following columns and structure: | Element / Transition | Content | | :--- | :--- | | **Mission Map** | [Provide a real-life scenario or daily project connecting ALL classes logically. CRITICAL: Maximum 60 words.] | | **Transition: Class 1 to Class 2** | **Logical Bridge:** [Explain why the student needs Topic B right after Topic A. Write this explaining the logic directly to the student].<br><br>**Teacher Script (Frase Puente):** [The exact text in English the teacher must say out loud. CRITICAL: Use casual, natural, and everyday English—keep it friendly and straightforward, avoiding over-complicated or robotic vocabulary. It must seamlessly connect the topics, explicitly mention the communicative objective, and organically guide students to the material/page without saying "class 2" or "next topic"]. | | **Transition: Class 2 to Class 3** | **Logical Bridge:** [Same as above for this transition].<br><br>**Teacher Script:** [Same as above for this transition using casual, everyday English]. | | *(Repeat rows for as many transitions as the user's block requires)* | | KEY TONE & STYLE GUIDELINES: 1. NEVER use forbidden transition phrases such as "Now open class X", "Next topic", or "Time is up". The tone must be collaborative, practical, creative, and strictly focused on fulfilling the institutional evaluation criterion: "Promueve la transición entre clases de forma fluida realizando una conexión sutil entre las temáticas a abordar y ubicando a los estudiantes en el material de estudio." 4.
